# 1. People (บุคลากร)

ผู้ที่เกี่ยวข้องกับระบบ ได้แก่

- เจ้าของร้าน
- ผู้จัดการ
- พนักงานรับออเดอร์
- บัญชีร้าน
- ลูกค้า
- ผู้จัดวัตถุดิบ

---

# 2. Process (กระบวนการ)

ลำดับการทำงานของระบบ

1. ลูกค้าแจ้งความต้องการสั่งสินค้า
2. พนักงานรับออเดอร์
3. บันทึกรายการสั่งซื้อ
4. ระบบบันทึกคำสั่งซื้อ
5. ชำระเงิน
6. สร้างหมายเลขออเดอร์
7. แจ้งรายละเอียดให้ลูกค้า
8. ระบบสต็อกสินค้า
9. ตัดสต็อก
10. กดแจ้งสินค้าพร้อมขาย
11. เจ้าของร้านตรวจสอบรายงานยอดขาย

---

# 3. Data (ข้อมูล)

ข้อมูลที่ใช้ในระบบ ได้แก่

- ข้อมูลลูกค้า
- เมนูเครื่องดื่ม
- ราคา
- รายการสั่งซื้อ
- ข้อมูลการชำระเงิน
- ข้อมูลสต็อกวัตถุดิบ
- ยอดขาย

---

# 4. Hardware (ฮาร์ดแวร์)

อุปกรณ์ที่ใช้ในระบบ

- คอมพิวเตอร์
- เครื่อง POS
- เครื่องอ่านบาร์โค้ด
- เครื่องพิมพ์ใบเสร็จ
- เครื่องเช็กสต็อก

---

# 5. Software (ซอฟต์แวร์)

โปรแกรมที่ใช้

- Program POS
- ระบบจัดการสต็อก
- ระบบฐานข้อมูล
- โปรแกรมรายงานยอดขาย
- โปรแกรมบัญชี

---

# 6. Network (เครือข่าย)

ระบบเครือข่ายที่ใช้

- Internet
- Wi-Fi ภายในร้าน
- Router
- Cloud Database
- Server สำหรับเก็บข้อมูล

# แนวคิดการพัฒนา

## เลือกใช้ Agile

### เหตุผล

1. **ความต้องการของร้านอาจเปลี่ยนแปลงได้ตลอดเวลา**
   - ร้านอาจเพิ่มหรือเปลี่ยนเมนูในภายหลัง
   - Agile รองรับการเปลี่ยนแปลงได้ดี

2. **สามารถใช้งานได้เร็ว**
   - เริ่มจากระบบขาย (POS)
   - แล้วค่อยเพิ่มระบบสมาชิก
   - ระบบสต็อก
   - ระบบรายงานภายหลัง

3. **พัฒนาและทดสอบเป็นรอบ ๆ**
   - เจ้าของร้านสามารถให้ความคิดเห็นหลังการทดสอบ
   - ปรับปรุงระบบให้ตรงกับความต้องการได้ง่าย
